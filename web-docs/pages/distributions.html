Normal vs SemiExtended Width

Declared in private-build-plans.toml under widths.Normal and widths.SemiExtended.

shape = 500 · css = normal

Normal (500)

The default coding width. Dense enough for side-by-side diffs and split panes while keeping counters open at 12–14px.

Core NF scope: 8 Normal coding weights
shape = 548 · css = semi-expanded

SemiExtended (548)

About 10% wider cells for high-DPI displays, presentations, and readers who prefer more horizontal breathing room.

Extended-Core NF scope: 8 SemiExtended coding weights
