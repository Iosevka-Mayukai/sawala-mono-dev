Complete Programming Ligatures Catalog

Curated reference of 55 OpenType default-calt substitutions shipped in Sawala Mono. Each row shows the literal ASCII input (rendered in Sawala Mono NL) beside the fused ligature, so you can judge every operator before enabling ligatures in your editor.

Ligatures never change the advance width: a three-character operator still occupies exactly three monospace cells, so column alignment in diffs and tables stays intact.
