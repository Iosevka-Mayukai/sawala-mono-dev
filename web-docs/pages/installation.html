INSTALLATION GUIDE

Installing Sawala Mono on Your System

Step-by-step instructions for Windows, macOS, Linux, and terminal-first environments. Pick your operating system below, then copy a ready-made editor configuration from the main showcase.

Windows · macOS · Linux TTF desktop binaries No admin rights needed on Linux

Choose Your Operating System

The same steps apply to every distribution; only the archive name and the family name you configure change.

  1. Download the archive

    Get SawalaMono-v1.0.0.zip (or the NL / NF variant) from GitHub Releases.

  2. Extract the archive

    Right-click the ZIP and choose Extract All… into any folder.

  3. Install for all users

    Select every .ttf file, right-click, and choose Install for all users. This avoids per-user font permission issues in Java runtimes (JetBrains IDEs) and some terminal emulators.

  4. Configure your editor

    Set the font family to 'Sawala Mono', monospace in VS Code, Windows Terminal, or your IDE, then restart the application.

iTip: If JetBrains IDEs do not list the font, confirm it was installed for all users and restart the IDE completely.

  1. Download the archive

    Get the ZIP for your preferred variant from GitHub Releases; Safari extracts it automatically.

  2. Open Font Book

    Press Cmd + Space, type Font Book, and press Return.

  3. Add the fonts

    Drag the extracted TTF/*.ttf files into the Font Book window, or copy them from the terminal:

    cp ~/Downloads/SawalaMono-v1.0.0/SawalaMono/TTF/*.ttf ~/Library/Fonts/

  4. Restart your editor

    Quit and reopen your editor or terminal so it picks up the new font family.

iTip: Font Book flags duplicate families. Remove older Sawala Mono builds before installing a new release.

  1. Download and extract

    Fetch the release archive and unzip it:

    curl -LO https://github.com/Iosevka-Mayukai/sawala-mono-dev/releases/download/v1.0.0/SawalaMono-v1.0.0.zip
unzip SawalaMono-v1.0.0.zip -d SawalaMono-v1.0.0

  2. Copy to your user fonts directory

    Standard builds nest font binaries inside SawalaMono/TTF/ (no root access required):

    mkdir -p ~/.local/share/fonts/SawalaMono
cp SawalaMono-v1.0.0/SawalaMono/TTF/*.ttf ~/.local/share/fonts/SawalaMono/

  3. Refresh the font cache

    Rebuild fontconfig's cache so applications can see the family:

    fc-cache -f -v

  4. Verify the installation

    The family should appear in the fontconfig listing:

    fc-list | grep "Sawala Mono"
iTip: For a system-wide install, copy the files to /usr/local/share/fonts/ with sudo instead.

  1. No package manager formula yet

    Sawala Mono is not yet published as a Homebrew cask or AUR package. Until it is, use this reproducible scripted install on macOS (with Homebrew tools) or Arch Linux.

  2. Download the release

    Pick the variant you need (standard, NL, NF, or NL NF):

    curl -LO https://github.com/Iosevka-Mayukai/sawala-mono-dev/releases/download/v1.0.0/SawalaMono-NF-v1.0.0.zip
unzip SawalaMono-NF-v1.0.0.zip -d SawalaMonoNF

  3. Install into the user font directory

    macOS uses ~/Library/Fonts; Arch uses ~/.local/share/fonts:

    # macOS
cp SawalaMonoNF/*.ttf ~/Library/Fonts/

# Arch Linux
mkdir -p ~/.local/share/fonts/SawalaMonoNF
cp SawalaMonoNF/*.ttf ~/.local/share/fonts/SawalaMonoNF/ && fc-cache -f

  4. Point your terminal at the NF family

    Use Sawala Mono NF (or Sawala Mono NL NF) in Kitty, WezTerm, Alacritty, or Starship-based prompts.

iTip: Watch the repository releases to be notified when an official cask or AUR package becomes available.

After Installing

Configure the family name in your editor or terminal emulator.
