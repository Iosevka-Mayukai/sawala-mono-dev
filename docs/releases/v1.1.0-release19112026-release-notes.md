# Release Notes — v1.1.0-release19112026 (2026-11-19)

This release adds **Sawala Ligar Mono** and **Sawala Ligar Mono NF**, expanding the Sawala Mono family from four distributions to six. It also refines the italic `y` glyph in **Sawala Mono** and **Sawala Mono NL**, updates the live web showcase with a six-font comparison panel, and tightens archive isolation across the CI build and Nerd Font patching workflows.

The name comes from the Sundanese word ***ligar*** (*blooming*, *opening out*). Where **Sawala Mono** stays crisp and geometric, **Sawala Ligar Mono** introduces subtle curves on selected diagonal and terminal strokes while keeping the same proportions, weights, widths, and programming ligatures.

---

## Highlights

- **New Distributions — Sawala Ligar Mono & Sawala Ligar Mono NF:** A selective-curly sibling built on the `ss20` preset with full `default-calt` programming ligatures, sharing the same 9 weights, 2 widths (`Normal` `500`, `SemiExtended` `548`), and `9.4°` italic slope as Sawala Mono.
- **Italic Refinement for Sawala Mono & Sawala Mono NL:** Updated italic `y` to `cursive-serifless` in both baseline distributions so it matches the flow of the rest of the italic character set.
- **Six-Font Comparison Panel on the Live Showcase:** The interactive showcase at [iosevka-mayukai.github.io/sawala-mono-dev](https://iosevka-mayukai.github.io/sawala-mono-dev/) now pairs a full-alphabet JavaScript specimen with six selectable baseline fonts for direct side-by-side inspection.
- **Hardened Multi-Variant CI & Patching:** Both the font compiler and Nerd Font patcher workflows now support `SawalaLigarMono`, use a 150-minute job timeout for full multi-variant builds, and enforce strict per-variant archive isolation.

### 2. Meet Sawala Ligar Mono

Configured under `[buildPlans.SawalaLigarMono]` in [private-build-plans.toml](https://github.com/Iosevka-Mayukai/sawala-mono-dev/blob/v1.1.0-release19112026/private-build-plans.toml):

- **Shared Metric Core:** Uses the exact same `Normal` (`500`) and `SemiExtended` (`548`) widths, `0°` upright and `9.4°` italic slopes, and `default-calt` ligatures as Sawala Mono. Because it registers under its own family names (`Sawala Ligar Mono` and `Sawala Ligar Mono NF`), it installs cleanly alongside existing Sawala Mono fonts without naming conflicts.
- **Upright (`0°`) Design:** Inherits from `ss20` with `curly-serifless` `7`, `x`, and `z`; `double-storey-tailed` `a`; `toothed-serifless` `b`, `d`, and `u`; `earless-corner-double-arch-serifless` `m`; `no-base-long-top-serif` `1`; `closed-serifless` `4`; `reverse-slashed` `0`; round punctuation dots; `large-contour` parentheses; and `curly-flat-boundary` braces.
- **Italic (`9.4°`) Design:** True cursive italic combining `cursive-serifless` `k` and `y` with `curly-serifless` `v`, `w`, `x`, and `z`; `single-storey-tailed` `a`; `single-storey-serifless` `g`; `earless-rounded-double-arch-serifless` `m`; `flat-hook-tailed` `f`; `serifed-semi-tailed` `i` and `l`; `straight-serifless` capital `A`, `n`, and `q`; `eared-serifless` `p`; and `reverse-slashed` `0`.

## Upgrade & Migration Guide

1. **Upgrading from `v1.0.0`:**
   - Replace your existing **Sawala Mono** or **Sawala Mono NL** font files if you want the updated italic `y` glyph.
   - **Windows:** Extract the `.zip`, select all `.ttf` files, right-click, and choose **"Install for all users"** (recommended for JetBrains IDEs and Java runtimes).
   - **macOS:** Drag the extracted `.ttf` files into **Font Book** and confirm replacement when prompted.
   - **Linux:** Copy the `.ttf` files into `~/.local/share/fonts/SawalaMono/` and refresh the cache with `fc-cache -f -v`.
2. **Editor & Terminal Configuration:**
   - To try the new selective-curly variant, set your IDE font family to `"Sawala Ligar Mono"` (with ligatures enabled), or `"Sawala Ligar Mono NF"` in terminal emulators and Neovim.
   - See [README.md](https://github.com/Iosevka-Mayukai/sawala-mono-dev/blob/v1.1.0-release19112026/README.md) for ready-to-use snippets for VS Code, JetBrains IDEs, Neovim/Neovide, Alacritty, Kitty, WezTerm, and Windows Terminal.
3. **Breaking Changes:**
   - None. All existing `Sawala Mono`, `Sawala Mono NL`, `Sawala Mono NF`, and `Sawala Mono NL NF` family names and archive naming patterns remain backward-compatible with `v1.0.0`.

## Bug Fixes & Stability

- **Multi-Variant Build Pipeline:** Added `SawalaLigarMono` as a workflow target in [.github/workflows/build.yml](https://github.com/Iosevka-Mayukai/sawala-mono-dev/blob/v1.1.0-release19112026/.github/workflows/build.yml) and increased `timeout-minutes` to `150` so `variant: all` completes reliably across all three build plans.
- **Nerd Font Patcher Hardening:** Updated [.github/workflows/patch-nerd-font.yml](https://github.com/Iosevka-Mayukai/sawala-mono-dev/blob/v1.1.0-release19112026/.github/workflows/patch-nerd-font.yml) to support `SawalaLigarMono`, raised the timeout to `150` minutes, tightened archive filtering to exact prefixes (`${VARIANT}-*.zip`) so sibling archives cannot leak across variants, and added a validation guard preventing `NL` / `Ligar` naming collisions when `custom_name` is combined with `variant: all`.
