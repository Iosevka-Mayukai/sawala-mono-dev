# Release Notes — v1.0.0 (2026-11-13)

Welcome to the first stable release of **Sawala Mono** (`v1.0.0`), a developer-centric monospace coding typeface built on top of [Iosevka v34.9.1](https://github.com/be5invis/Iosevka).

Named after the Sundanese word ***sawala*** (*discussion*, *deliberation*, or *intellectual exchange*), Sawala Mono is engineered around a simple principle: code is read, reviewed, and reasoned about by humans far more often than it is written. Every glyph choice, proportion, and distribution variant is tuned for long-session legibility across IDEs, code reviews, and terminal workflows.

---

## Highlights

- **Four Purpose-Built Distributions:** Ships as **Sawala Mono** (with programming ligatures), **Sawala Mono NL** (*No Ligatures*), **Sawala Mono NF** (*Nerd Font*), and **Sawala Mono NL NF** (*Nerd Font + No Ligatures*)—all sharing one parametric metric core (`Normal` width `500`, `SemiExtended` width `548`, `9.4°` italic slope).
- **Refined Human-Centric Glyph Geometry:** Built on the `ss03` preset with high-distinction character shapes including `reverse-slashed` zero (upright) and `tall-reverse-slashed` zero (italic), `curly-flat-boundary` braces, `large-contour` parentheses, `base-long-top-serif` `1`, `bend-serifless` `7`, and semi-tailed cursive italic forms.
- **Automated Cloud Build & Nerd Font Patching:** Includes containerized GitHub Actions workflows for reproducible TTF/WOFF2 font builds and standalone Nerd Font (`--mono --complete`) patching across `core`, `extended-core`, and `all` weight scopes.
- **Interactive Web Showcase & Documentation:** Includes a static documentation and live font-testing site deployed via GitHub Pages with a polyglot code runner, ligature playground, glyph inspector, and editor configuration generator.

### 2. Typography & Design Specifications

Configured declaratively in [private-build-plans.toml](../../private-build-plans.toml):

- **Shared Structural Core:** Sans-serif base (`serifs = "sans"`), normal spacing (`spacing = "normal"`), `ss03` character variant inheritance, and dedicated family namespaces that install cleanly side-by-side with upstream Iosevka.
- **Upright (`0°`) Key Variants:** Double-storey tailed `a`, toothless corner serifless `b`/`d`/`u`, earless corner `m`/`n`/`p`/`q`, symmetric connected `k`, `large-contour` parentheses, `curly-flat-boundary` braces, and `reverse-slashed` `0`.
- **Italic (`9.4°`) Key Variants:** True cursive-inspired italic with single-storey `a` and `g`, flat-bottom `b`/`d`, flat-hook tailed `f`, serifed semi-tailed `i`/`l`, cursive `k`, flat-hook short-neck `t`, and `tall-reverse-slashed` `0`.

### 3. CI/CD Workflows & Interactive Showcase

- **Docker Font Compiler CI:** Containerized build pipeline in [.github/workflows/build.yml](../../.github/workflows/build.yml) supporting `variant` (`all`, `SawalaMono`, `SawalaMonoNL`), `format` (`ttf`, `woff2`, `contents`), and automated GitHub Release packaging.
- **Standalone Nerd Font Patcher CI:** Containerized `nerdfonts/patcher:latest` workflow in [.github/workflows/patch-nerd-font.yml](../../.github/workflows/patch-nerd-font.yml) with `variant`, `patch_mode` (`complete`, `default`), `font_scope` (`core`, `extended-core`, `all`), and `custom_name` override support.
- **Static Web Showcase & GitHub Pages CI:** Interactive showcase site ([index.html](../../index.html), `web-docs/`, and [.github/workflows/pages.yml](../../.github/workflows/pages.yml)) featuring live WOFF2 rendering, a 5-language polyglot runner with Prism.js syntax highlighting, ligature catalog, distribution matrix, and OS/editor setup generators.

## Upgrade & Migration Guide

1. **Upgrading from `v1.0.0-beta*` Pre-releases:**
   - Remove previously installed `v1.0.0-beta*` font files before installing `v1.0.0` to prevent stale font-cache conflicts.
   - **Windows:** Extract the `.zip`, select all `.ttf` files, right-click, and choose **"Install for all users"** (recommended for JetBrains IDEs and Java runtimes).
   - **macOS:** Drag the extracted `.ttf` files into **Font Book** and confirm replacement if prompted.
   - **Linux:** Copy `.ttf` files to `~/.local/share/fonts/SawalaMono/` and run `fc-cache -f -v`.
2. **Environment / Editor Config Changes:**
   - Configure `"Sawala Mono"` (or `"Sawala Mono NL"` with `"editor.fontLigatures": false`) in IDEs, and `"Sawala Mono NF"` (or `"Sawala Mono NL NF"`) in terminal emulators and Neovim.
   - See [README.md](../../README.md) for copy-paste configuration snippets for VS Code, JetBrains IDEs, Neovim/Neovide, Alacritty, Kitty, WezTerm, and Windows Terminal.
3. **Breaking Contract Changes:**
   - None for `v1.0.0` initial stable release. If you consumed earlier beta Nerd Font archives, note that `SemiExtended` Nerd Font builds are now packaged separately as `*-Extended-NF-<tag>.zip` when built with `font_scope: extended-core`.

## Bug Fixes & Stability

- **Glyph & Variant Standardization:** Standardized upright and italic glyph identifiers in [private-build-plans.toml](../../private-build-plans.toml) (`n`, `b`, `six`, `nine`, `l`), added the missing italic `i` variant (`serifed-semi-tailed`), and aligned italic `zero` to `tall-reverse-slashed`.
- **Build & Packaging Reliability:** Refined environment variable handling and release title generation in [.github/workflows/build.yml](../../.github/workflows/build.yml), upgraded `docker/build-push-action` to `v6`, and ensured intermediate `TTF-Unhinted` / `WOFF2-Unhinted` directories are stripped from final release archives.
- **Nerd Font Patching Hardening:** Added strict variant filtering, `extended-core` scope support, and automatic `NL` suffix handling for `custom_name` overrides in [.github/workflows/patch-nerd-font.yml](../../.github/workflows/patch-nerd-font.yml).
- **Lean Repository Footprint:** Streamlined downstream fork assets while preserving upstream compiler dependencies (`build-plans.toml`, `packages/*`, `tools/*`, and `doc/` references), documented in [docs/ARCHITECTURE.md](../ARCHITECTURE.md).
