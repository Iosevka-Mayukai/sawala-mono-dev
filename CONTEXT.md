# Iosevka Sawala Mono

Domain glossary for the Sawala Mono customized coding typeface family and its distribution variants.

## Language

**Sawala Mono**:
The baseline monospace coding typeface distribution with standard earless/toothless glyph geometry and contextual programming ligatures.
_Avoid_: Standard Sawala, Sawala Default

**Sawala Mono NL**:
The no-ligatures monospace coding typeface distribution preserving strict literal operator symbol separation.
_Avoid_: Sawala Unligated, Sawala Without Ligatures

**Sawala Ligar Mono**:
The expressive selective-curly monospace coding typeface distribution inspired by the Sundanese word *ligar* (blooming or opening gracefully) with contextual programming ligatures.
_Avoid_: Sawala Curly, Sawala Mono Curly, Sawala Ligar

**Sawala Mono NF**:
The Nerd Font patched distribution of Sawala Mono containing developer and Powerline icon glyphs.
_Avoid_: Sawala Nerd Font, Sawala Icons

**Sawala Mono NL NF**:
The Nerd Font patched distribution of Sawala Mono NL combining unligated operator glyphs with developer icons.
_Avoid_: Sawala Unligated Nerd Font

**Sawala Ligar Mono NF**:
The Nerd Font patched distribution of Sawala Ligar Mono combining selective-curly letterforms and programming ligatures with developer icons.
_Avoid_: Sawala Ligar NF, Sawala Curly NF

**Build Plan ID**:
The exact alphanumeric section key (`SawalaMono`, `SawalaMonoNL`, `SawalaLigarMono`) identifying a font family build plan and its release archive prefix.
_Avoid_: Family Display Name, Variant Label
